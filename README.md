# 📈 Stock Market Prediction using LSTM

This project predicts stock prices using **LSTM (Long Short-Term Memory)** networks built with Keras and TensorFlow.

## 🧠 Features
- Data preprocessing using `MinMaxScaler`
- Model built with stacked LSTM layers
- Visualization of predicted vs. actual prices

## ⚙️ Technologies
- Python
- Pandas, NumPy, Matplotlib
- Keras / TensorFlow
- Scikit-learn

## 📊 Results
The model learns trends over time and predicts stock price movement effectively.
